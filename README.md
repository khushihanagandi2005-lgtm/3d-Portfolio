# Khushi H — 3D Portfolio

A personal developer portfolio built with **React, TypeScript, Vite, and Tailwind CSS**. This portfolio showcases my introduction, skills, services, projects, and contact information through a modern and interactive design.

## 🚀 Features

- Modern and responsive portfolio design
- Attractive hero section with personal introduction
- About section highlighting skills and background
- Services section showcasing technical expertise
- Projects section displaying selected work
- Contact section for professional connections
- Reusable React components
- Responsive navigation and layouts

## 🛠️ Tech Stack

- **Frontend:** React 19
- **Language:** TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS 4
- **Linting:** Oxlint




💻 Getting Started

Follow these steps to run the project locally.

Prerequisites:
Make sure you have installed:
- Node.js
- npm
 Installation

1. Clone the repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**
```bash
cd 3d-portfolio
```

3. Install dependencies
```bash
npm install
```

4. Start the development server
```bash
npm run dev
```

Open the local URL displayed in your terminal to view the portfolio.

📜 Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the development server |
| `npm run build` | Creates the production build |
| `npm run preview` | Previews the production build |
| `npm run lint` | Runs code linting |

🎨 Customization

You can customize your portfolio by editing:

- `src/data/portfolio.ts` – Update personal information, services, and projects.
- `src/components/` – Modify individual portfolio sections.
- `src/index.css` – Customize global styles.
- `public/` – Add or replace images and other static assets.

🌐 Deployment

You can deploy your portfolio using platforms such as:

- Vercel
- Netlify
- GitHub Pages

First, generate the production build:

```bash
npm run build
```

The optimized production files will be available in the `dist` directory.
